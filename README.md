# ТТ-Детектор

Разбирает черновики технических требований: показывает дефекты формулировок
с цитатами, вопросы, которые задаст исполнитель, и переписанные формулировки
со списком допущений.

## Запуск локально

```bash
pip install -r requirements.txt
python -m uvicorn app:app --app-dir backend --port 8000
```

Открыть http://localhost:8000

Ключ модели кладётся в `.env` в корне (образец — `.env.example`). Провайдер
выбирается по наличию ключа: `GIGACHAT_CREDENTIALS`, `GEMINI_API_KEY` или
`ANTHROPIC_API_KEY`; можно задать явно через `LLM_PROVIDER`.

## Как устроен разбор

Прямой вопрос «разбери документ целиком» модели среднего класса не по силам:
на тексте в 13 тысяч знаков она делает поверхностный проход. Замеры на
GigaChat-2-Max по эталонной паре (13 размеченных правок):

| Способ | Найдено | Конфликт по SCADA |
|---|---|---|
| Документ целиком, один запрос | 2 | не найден |
| По разделам | 5 | не найден |
| По разделам + подобранные пары + узкие проходы | 9–10 | найден 3/3 |
| То же плюс формальные проверки | **11 из 13** | найден 3/3 |

Ориентир ТЗ — «порядка десяти из тринадцати», снятый вручную на ChatGPT
и DeepSeek. Достигнут.

Проходы:

1. **`backend/formal.py`** — регулярные выражения, без модели, миллисекунды.
2. **Проход по разделам** — документ режется по заголовкам верхнего уровня,
   каждый раздел разбирается отдельно.
3. **Узкие проходы по типам 2 и 7** — в общем потоке модель не выделяет их
   ни разу; будучи спрошенной только о них, находит.
4. **Проход по парам** — кандидаты на конфликт подбираются детерминированно,
   модель лишь сравнивает пару. Два способа подбора дополняют друг друга:
   по общему редкому термину (так находится конфликт по SCADA) и от абзаца,
   сужающего область действия (так находится конфликт по границам
   моделирования, где общего термина у фрагментов нет).

Выдача фильтруется перед показом: цитата, которой нет в исходном документе,
отбрасывается. Модель изредка сочиняет требование целиком, а продукт обещает
дословную цитату — рецензент, не нашедший фразу у себя, перестанет верить
всему разбору. Также отбрасываются цитаты из ячеек таблиц и заголовков.

Задания независимы и идут в три потока: последовательно разбор занимает около
пяти минут, параллельно — около минуты.

## Режим примера

Публичный пример — синтетический документ `data/demo_v2.md` («Система
мониторинга холодильного оборудования торговой сети») с разметкой
`data/demo_edits.json`. Он написан специально для демонстрации: разбор виден
всякому, кто откроет ссылку, и класть туда рабочий документ нельзя.

> Разметку к синтетическому документу составлял тот же человек, что писал сам
> документ, поэтому счёт на нём показывает механику, а не независимо измеренную
> точность. Независимая метрика снимается на приватной эталонной паре
> (`data/concept_v2.md` + `data/reference_edits.json`) — реальной истории
> ручных правок; в репозиторий она не попадает.

Разбор примера считается заранее и лежит в `runs/example.json`, поэтому кнопка
«Попробовать на примере» срабатывает мгновенно и не обращается к модели.
Пересчитать:

```bash
python scripts/build_example.py                   # полный прогон, ~90 с
python scripts/build_example.py --refresh-formal  # только правила и метрика
```

Без файлов примера режим отключается с явным сообщением.

## Проверки

```bash
python scripts/gate.py 3        # гейт устойчивости: конфликт по SCADA во всех прогонах
python scripts/score.py runs/gate_run_*.json   # полнота по эталонной разметке
python backend/formal.py        # формальные проверки на эталонном документе
```

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/formal` | Формальные проверки. Синхронно, миллисекунды. |
| POST | `/api/analyze` | Разбор модели по схеме из §4.1 ТЗ. |
| POST | `/api/example` | Эталонный документ + блок совпадения (из кеша). |
| POST | `/api/upload` | Извлечение текста из `.docx`, `.txt`, `.md`. |
| GET | `/api/health` | Готовность, выбранный провайдер, лимит. |

Лимит входа — 40 000 знаков. Документы пользователя не сохраняются:
обработка в памяти, базы нет, содержимое не логируется.

## Развёртывание

Нужен один процесс: `python backend/app.py` (порт берётся из `PORT`).
Переменные окружения — те же, что в `.env`.

> ГигаЧат может быть недоступен с зарубежных адресов. На главный сценарий
> демонстрации это не влияет: кнопка «Попробовать на примере» отдаёт готовый
> разбор из кеша и обращений к модели не делает. Разбор произвольного текста
> в этом случае вернёт честную ошибку.
